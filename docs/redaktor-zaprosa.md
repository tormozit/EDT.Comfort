# Редактор запроса

Под этим именем в документации объединены **три места** в EDT, где редактируется текст запроса:

| Место | Описание |
|-------|----------|
| **Редактор запроса** | окно "Редактор запроса"
| **Схема компоновки данных** | поле текста запроса в редакторе схемы компоновки
| **Динамический список** | поле текста запроса в окне "Динамический список"

Общие функции текстового поля (быстрый поиск, навигация по идентификатору, вставка со сравнением, контекстное меню) — [Редакторы текста](redaktory-teksta.md).
В модальном редакторе запроса Eclipse не доставляет стандартные привязки клавиш — Комфорт перехватывает **Ctrl+F3** / **Ctrl+Shift+F3** на уровне окна.

## Автодополнение

Во всех трёх редакторах запросов работает [автодополнение](avtodopolnenie.md) с умным фильтром и поддержкой ИР ([#132](https://github.com/tormozit/EDT.Comfort/issues/132)).

## Конструктор запроса EDT :id=konstruktor-zaprosa-edt

В штатном конструкторе запроса EDT список доступных таблиц использует [многословный фильтр](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) Комфорт (с раскраской вхождений) вместо штатного ([#81](https://github.com/tormozit/EDT.Comfort/issues/81)).

Конструктор, открытый из модуля для пакета запросов, сразу открывает запрос пакета, в котором стоит каретка.

Если в тексте запроса есть комментарии, при открытии конструктора показывается уведомление о том, что при разборе текста они потеряны, с началом их текста (до 100 символов). Учитываются только комментарии с буквами: разделители вроде `//////` не считаются. Для конструктора, открытого из модуля, в уведомлении есть ссылка **«Открыть конструктор ИР»**: она закрывает штатный конструктор без изменений и открывает [конструктор запроса ИР](obshchie-mekhanizmy.md#komandy-ir-v-redaktore-bsl), который комментарии сохраняет.

В заголовках вкладок — число элементов в списках вкладки, например **Группировки (0)**; у вкладки с несколькими списками — их сумма. Списки доступных таблиц и полей не считаются.

Во всех списках полей конструктора есть узкая колонка **Тип** с типом значения поля; флажок **«Типы»** внизу окна (по умолчанию выключен) включает и выключает её во всех списках сразу. В контекстном меню её ячеек — [команды описания типов](obshchie-mekhanizmy.md#perehod-k-opredeleniyu), а у полей таблиц метаданных — **«Открыть в редакторе»** и **«Показать в навигаторе»** для реквизита поля ([#839](https://github.com/tormozit/EDT.Comfort/issues/839)).

## ИР

При подключённом ИР доступны команды ([#150](https://github.com/tormozit/EDT.Comfort/issues/150)):

- **Форматировать текст ИР** для текста запроса.
- **Редактор ИР** — команда в контекстном меню, открывает редактор текста ИР в псевдомодальном режиме.
- **Конструктор запроса ИР** — открывает конструктор запроса ИР ([#180](https://github.com/tormozit/EDT.Comfort/issues/180)).

См. [Команды ИР](obshchie-mekhanizmy.md#komandy-ir-v-redaktore-bsl).
