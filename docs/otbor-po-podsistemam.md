# Отбор по подсистемам

Диалог **Отбор по подсистемам** (в коде EDT — «Фильтр по подсистемам») в навигаторе; тот же диалог используется в **[сравнении конфигураций](sravnenie-konfiguracij.md)** для отбора по стороне сравнения.

## Возможности Комфорт

- Автораскрытие ветки проекта по текущему выделению в навигаторе.
- Запоминание размеров и положения окна между сеансами.
- Штатное поле фильтра заменено на [фильтр по подстроке](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) Комфорт с раскраской вхождений и историей запросов (**Ctrl+↓**) ([#82](https://github.com/tormozit/EDT.Comfort/issues/82)).
- Кнопка **Комфорт** на панели инструментов (и то же в контекстном меню дерева) — **Установить пометку с потомками** / **Снять пометку с потомками** для выделенной подсистемы; недоступно при включённом **«Включать объекты из подчинённых подсистем»**.
- **Ctrl+клик** по серой (унаследованной) пометке превращает соседние динамические пометки в статические, не сбрасывая пометки всего поддерева, как это делает штатное поведение — подсказка об этом выводится под деревом.
- Групповая установка флажков (клик по ветке, кнопки «Отметить все»/«Снять отметку со всех») больше не сбрасывает уже помеченное поддерево при пометке последнего непомеченного потомка или уже полностью помеченного родителя ([#82](https://github.com/tormozit/EDT.Comfort/issues/82), [#228](https://github.com/tormozit/EDT.Comfort/issues/228)).
- Кнопка **«Снять отметку со всех»** теперь всегда доступна (штатно отключалась при включённом «Включать объекты из подчинённых/родительских подсистем», пока не помечены все корни).
- **Ctrl+C** на дереве копирует текст активной ячейки.
- Для диалога, открытого из **сравнения конфигураций**, — запоминание выбранной стороны (главная/другая конфигурация) на время сессии сравнения.
- Флажок **«Скрывать объекты выбранных подсистем (чёрный список)»** — выбранные подсистемы **скрывают** объекты вместо штатного белого списка ([#241](https://github.com/tormozit/EDT.Comfort/issues/241)).
- В меню **Комфорт** (панель инструментов и контекстное меню дерева) — **«Сохранить состояние фильтра…»** и **«Загрузить состояние фильтра…»**: пометки подсистем, флаги «Включать объекты из…», режим чёрного списка ([#243](https://github.com/tormozit/EDT.Comfort/issues/243)).

## Наборы объектов

**В этом диалоге наборы объектов не показываются** — только штатное дерево подсистем. Фильтрация по набору — отдельная кнопка **Фильтр по набору** в [навигаторе](navigator.md); см. [Наборы объектов](nabory-obektov.md).
