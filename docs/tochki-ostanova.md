# Точки останова

Штатная панель EDT **Точки останова**. Отдельно — точки останова по исключению (строка вида
«Сообщение исключения: […]»).

## Возможности Комфорт

- Двойной клик по строке точки останова по исключению открывает редактор текста фильтра сообщения
  вместо пустого штатного диалога «Свойства точки останова…» (EDT не регистрирует страницу свойств
  для такой точки останова, только для точки останова по строке).
- Команда **«Свойства точки останова…»** для такой строки тоже перехватывается и открывает тот же
  редактор фильтра вместо пустого информационного диалога.
- Диалог **«Остановка по ошибке»** (кнопка «Добавить точку останова по исключению») получает:
  - собственное поле фильтра с многословным AND-фильтром вместо штатного подстрочного;
  - суффикс « (Новая)» в заголовке — отличать от редактора существующей точки останова;
  - кнопку **«Вставить из буфера»** — читает буфер обмена, разбирает его штатным разборщиком
    трассировки EDT и подставляет найденную причину ошибки в поле фильтра; то же самое выполняется
    один раз автоматически при открытии диалога.
- В диалоге **«Свойства для …»** точки останова строки группы **«Условия»** и **«Действия»**
  разворачиваются автоматически при открытии, если внутри группы включена хотя бы одна пометка
  ([#275](https://github.com/tormozit/EDT.Comfort/issues/275)).
- Поля условия и значения выражения доступны для ввода сразу, без предварительного включения
  связанных флажков; при появлении текста флажок включается сам. При включении любого флажка
  группы **«Вывести в консоль»** автоматически включается **«Продолжить выполнение»**. Колесо
  мыши прокручивает содержимое диалога (в том числе когда курсор над этими полями).
- В полях условия и значения выражения работает [автодополнение](avtodopolnenie.md) с автооткрытием
  при вводе ([#274](https://github.com/tormozit/EDT.Comfort/issues/274)). Esc при открытом списке
  предложений закрывает только список, а не весь диалог свойств.
- Размер этого диалога запоминается: при следующем открытии окно получает те же ширину и высоту
  (в пределах размеров экрана).
- Двойной клик по причине ошибки в панели [Трассировка стека](trassirovka-steka.md) тоже открывает
  этот диалог и сразу подставляет причину — без буфера обмена.
