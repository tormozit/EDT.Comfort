# Редактор объекта метаданных

Редактор объекта конфигурации EDT — вкладки **Основные**, **Данные**, **Формы**, **Подсистемы** и другие.

## Число строк на вкладках-списках

В заголовках вкладок, которые показывают список (формы, команды, макеты, подсистемы, реквизиты и т. п.), отображается число строк этого списка ([#317](https://github.com/tormozit/EDT.Comfort/issues/317)).

- Для обычных списков объекта число берётся из объекта сразу и **не меняется** при открытии вкладки: **Формы** / **Команды** / **Макеты** — размер коллекции; **Данные** — число реквизитов плюс число табличных частей.
- Вкладки модулей (**Модуль объекта**, **Модуль менеджера** и т. п.): **(+)** если файл модуля есть и не пустой, **(-)** если файла нет или его размер 0.
- Если список нельзя взять из объекта (например, дерево **Подсистемы** с пометками), сначала в заголовке стоит **«?»**, число считается при первом переходе на вкладку.
- Для списков с пометками (например, **Подсистемы**) в заголовке — число **помеченных** элементов, а не всех строк дерева.
- Число обновляется при изменении состава списка.

Вкладки свойств (**Основные**) и встроенных редакторов (СКД, табличный документ) без списка не получают суффикс.
