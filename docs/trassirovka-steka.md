# Трассировка стека

Штатная панель EDT **Трассировки стека** — многостраничная, по вкладке на каждую трассировку.

## Возможности Комфорт

Доработки панели ([#256](https://github.com/tormozit/EDT.Comfort/issues/256)):

- Заголовок вкладки — вместо «Трассировка стека» обрезка до 30 символов первой строки текста
  ошибки с суффиксом «...»; дата/время под ней сохраняется как у EDT. Если текст обрезан, полная
  первая строка показывается в подсказке при наведении.
- Слева от стека — **таблица списка трассировок** вместо скрытых вкладок ([#265](https://github.com/tormozit/EDT.Comfort/issues/265)):
  колонки **«Ошибка»**, **«Дата»**, **«Проект»**, сортировка по дате, поле фильтра над таблицей,
  множественное выделение, **Del** закрывает выбранные трассировки. Ширины и порядок колонок,
  а также положение разделителя запоминаются; доступен [отбор по значению колонки](obshchie-mekhanizmy.md#otbor-po-znacheniyu-kolonki).
- Над деревом каждой вкладки — поле **Проект**: по умолчанию выбирается проект с максимальным
  покрытием модулей из кадров стека; при неоднозначности (несколько похожих проектов, в т.ч. при
  открытом сравнении конфигураций) можно сменить проект один раз для всей вкладки, не вызывая
  диалог выбора модуля на каждом кадре ([#253](https://github.com/tormozit/EDT.Comfort/issues/253)).
  Список проектов и резолв кадров выполняются только для **активной** вкладки; при смене вкладки
  и активации панели обновляется видимый стек (проекты, появившиеся позже старта EDT, тоже
  попадают в Combo).
- **Одинарный клик** по строке кадра стека только выделяет строку; **двойной клик** открывает
  соответствующую строку модуля **в выбранном проекте**. Штатный переход по смене выделения отключён.
  Если модуля нет в выбранном проекте, показывается тост; если тот же модуль найден в другом
  проекте workspace — в тосте перечисляются эти проекты.
- Иконки кадров стека: **красный крестик** — модуль не найден в выбранном проекте; **предупреждение** —
  модуль найден, но текст после «:» в строке стека не совпадает с текстом той же строки модуля.
  При двойном клике по такой строке модуль открывается на номере из стека, затем ниже по тексту
  ищется строка с тем же содержимым — если найдена, предлагается перейти к ней.
- Двойной клик по строке узла **причины** ошибки открывает окно **«Описание ошибки»** с полным
  текстом ([#276](https://github.com/tormozit/EDT.Comfort/issues/276)) — в дереве видна только
  первая строка. В окне две кнопки: **«Остановка по ошибке»** запускает штатный диалог
  [«Остановка по ошибке»](tochki-ostanova.md) с уже подставленной причиной (первая строка описания,
  без буфера обмена), **«Ссылки»** показывает объекты метаданных, упомянутые в тексте ошибки, и
  переходит к выбранному — как одноимённая кнопка в окне ошибки EDT.
- **Ctrl+C** / «Копировать» копирует текст только текущей выделенной строки дерева, а не всю
  трассировку целиком, как штатная команда этой панели. Копируется полное описание, даже если
  в строке видна только его первая строка.
- Корневая строка (узел **причины**) заканчивается на **«...»**, если у описания ошибки есть строки
  ниже первой ([#276](https://github.com/tormozit/EDT.Comfort/issues/276)): дерево рисует только
  первую строку, и теперь видно, что описание продолжается. Полный текст — в подсказке при
  наведении и в буфере по **Ctrl+C**.
