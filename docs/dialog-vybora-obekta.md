# Диалог выбора объекта

Диалоги открытия и выбора объектов метаданных.

- [Фильтры по подстроке](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) — здесь доступен и иерархический вариант (точка делит фильтр на секции «тип.имя»).
- [Открыть объект конфигурации](obshchie-mekhanizmy.md#otkryt-obekt-konfiguracii) — Ctrl+2; подстановка выделенного текста ([#116](https://github.com/tormozit/EDT.Comfort/issues/116))
- При пустом фильтре список последних объектов упорядочен по моменту открытия (новые сверху) ([#288](https://github.com/tormozit/EDT.Comfort/issues/288)).

## Выбор объектов

Диалог с деревом и пометками — например, добавление функциональных опций на вкладке редактора объекта.

- Если ни одна строка не помечена, двойной щелчок по текущей строке ставит на ней пометку и закрывает окно.
- В подписи флажка **Только помеченные (N)** число совпадает с числом пометок и обновляется при их изменении.

## Выбор предопределенных данных

- Элементы каждого уровня дерева отсортированы по имени по алфавиту ([#727](https://github.com/tormozit/EDT.Comfort/issues/727)).
- При включённой настройке **Улучшать списки** над деревом доступен многословный фильтр: все слова должны встречаться в имени в любом порядке. Совпадения подсвечиваются, история запросов сохраняется после закрытия окна.
- Родительские узлы найденных элементов остаются видимыми. Текущая строка сохраняется при изменении фильтра; если фильтр её скрыл, она возвращается при очистке или изменении запроса, когда снова становится видимой.
