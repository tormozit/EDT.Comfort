# Структура проекта

Представление **Структура проекта** (дерево файлов проекта в Eclipse, `Project Explorer`).

## Индикаторы связи папок с объектами

Для папок, в которых есть файл **`.mdo`**, к подписи добавляется суффикс ([#237](https://github.com/tormozit/EDT.Comfort/issues/237)):

| Суффикс | Значение |
|---------|----------|
| ` <объект>` | Объект **привязан** к конфигурации — его полное имя встречается в `Configuration.mdo` |
| ` <?>` | Файл mdo **есть на диске**, но объекта **нет** в конфигурации («осиротевший» объект) |

Папки без mdo-файла не декорируются. Для групповых папок без своего mdo (Catalogs, Forms, Documents и т.п.) выводится русское мн.ч. типа метаданных.

Сценарий «осиротевшего» mdo — см. [Git: восстановление и Configuration.mdo](git-izmeneniya.md#osirotevshij-mdo).

## Команды в подменю «Комфорт»

В контекстном меню дерева — подменю **Комфорт** ([#238](https://github.com/tormozit/EDT.Comfort/issues/238)):

| Действие | Клавиши | Описание |
|----------|---------|----------|
| Открыть объект | F2 | Открыть объект метаданных выбранного файла/папки в редакторе EDT |
| Показать в навигаторе | Ctrl+T | Выделить соответствующий объект в [навигаторе](navigator.md) |
| Свернуть все другие | — | Свернуть все ветки, кроме родителей текущего выделения ([общие механизмы](obshchie-mekhanizmy.md#svernut-vse-drugie)) |

Команды доступны, если для выбранного ресурса удаётся определить объект метаданных (аналогично [Git-панелям](git-izmeneniya.md)).

## Копирование имён (Ctrl+C)

**Ctrl+C** при выделении одного или нескольких элементов дополнительно кладёт в буфер **имена** файлов/папок (по одному на строку) — удобно для вставки в сторонние приложения ([#235](https://github.com/tormozit/EDT.Comfort/issues/235)). Подробнее — [Навигатор → Копирование имён](navigator.md#kopirovanie-imyon).
