# Git: история и изменённые файлы
Команды и доработки Комфорт в представлениях Git в EDT.
## Где работает
- панель **«Индексирование Git»**;
- панель **«История»**.
## Команды в списках файлов
В списках изменённых файлов конфигурации — подменю **Комфорт**:
| Действие | Клавиши | Описание |
|----------|---------|----------|
| Открыть в Навигаторе | Ctrl+T | Выделить соответствующий объект в [навигаторе](navigator.md) |
| Открыть объект | F2 | Открыть объект метаданных в редакторе EDT |
Команды доступны при выборе файла конфигурации, для которого удаётся определить объект метаданных.

## История
В списке файлов коммита — колонки **«Тип»** и **«Путь»** с полным именем объекта метаданных и поле [фильтра](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) с раскраской вхождений ([#184](https://github.com/tormozit/EDT.Comfort/issues/184), [#230](https://github.com/tormozit/EDT.Comfort/issues/230)).
В контекстном меню списка **коммитов** — команда **«Сравнить рабочий каталог с коммитом»** ([#21](https://github.com/tormozit/EDT.Comfort/issues/21)).
В диалоге **«Выбор коммита»** (команды сравнения с коммитом) — флажок **«Разрешить удаление объектов главного источника»** под штатными настройками. По умолчанию **включён** (штатное поведение); при снятии сравнение не предлагает удалять объекты, присутствующие только в главном источнике ([#242](https://github.com/tormozit/EDT.Comfort/issues/242)).
## Индексирование Git
В списке файлов панели отображается колонка **«Тип»**, полное имя метаданных; фильтр заменён на многословный с историей и раскраской ([#183](https://github.com/tormozit/EDT.Comfort/issues/183), [#230](https://github.com/tormozit/EDT.Comfort/issues/230)).
## Заменить на HEAD ревизию и «осиротевший» mdo :id=osirotevshij-mdo
Если объект метаданных **удалили** в EDT, а затем **восстановили только файлы mdo** через Git (без записи в `Configuration.mdo`), объект не появится в навигаторе и может «пропасть» из сравнения конфигураций. В [структуре проекта](struktura-proekta.md) такая папка помечается суффиксом **` <?>`**.
Команда **«Заменить на HEAD ревизию»** при обнаружении таких файлов **предупреждает** и при согласии **добавляет** указатель на объект в `Configuration.mdo` ([#236](https://github.com/tormozit/EDT.Comfort/issues/236)).
## Configuration.mdo — дубликаты
Перед **выгрузкой** и **обновлением конфигурации БД** Комфорт автоматически удаляет **дубли** child-записей в `Configuration.mdo` (одинаковые строки вида `<reports>Имя</reports>`), которые могут появиться после объединения конфигураций. При обнаружении дублей показывается уведомление с возможностью **«Показать различия»** ([#246](https://github.com/tormozit/EDT.Comfort/issues/246)).
