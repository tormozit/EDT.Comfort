# Синхронизация базы

Диалоги синхронизации конфигурации с информационной базой при обновлении приложений.

## Окно «Выбор действия»

При диалоге EDT **«Выбор действия»** (блокировка инфобазы для обновления):

- Заголовок окна содержит название обновляемого приложения. Приложение определяется по выполняющемуся обновлению EDT. Если связь установить не удалось, в заголовке указано **«приложение не определено»**, а кнопка завершения сеансов не отображается.
- Кнопка **«Завершить и обновить»** отображается только для серверной базы и завершает через RAC все её сеансы, **кроме сеансов конфигуратора**. Адрес и учётные данные RAS берутся с вкладки **RAS** конфигурации подключения к той же базе и тому же проекту, а RAC — из каталога конфигуратора приложения. Кластер и база дополнительно проверяются по серверу, порту и имени базы. После нажатия окно выбора и родительские модальные окна обновления скрываются: завершение сеансов и дальнейшее обновление не блокируют интерфейс EDT. После подтверждения удаления остальных сеансов через RAS выполняется штатное **«Повторить»**. При отмене завершения сеансов или ошибке окно выбора возвращается. Ожидание удаления одного сеанса — 60 секунд; новые подключения могут снова заблокировать обновление.

- Если к базе **подключено приложение ИР** и в [панели «Приложения»](prilozheniya.md) включена колонка **«Динамическое обновление»** — Комфорт автоматически выбирает **«Обновить динамически»** в диалоге блокировки.
- После **динамического обновления** — уведомление с предложением **переподключить приложение ИР** для обновления метаданных в сеансе ИР.
- При **исключительной блокировке** без возможности динамического обновления — предложение **отключить приложение ИР**, если оно блокирует обновление базы.

## Мастер «Обновление конфигурации в приложениях»

- Колонка **«Изменений»** — число объектов проекта, ожидающих синхронизации с базой строки. Заполняется **только для приложений, помеченных «Обновить»**. Пока сервис синхронизации EDT ещё поднимается, показывается `?`, затем число появляется само. Клик по числу открывает набор [«<Измененные ИмяБазы>»](nabory-obektov.md) — те же объекты списком.
- Флажок **«Исправлять проблемы после выгрузки в формат 8.5»** — убирает известный баг конвертации форм (лишний `ButtonImportance=Main` у кнопок).

См. [Интеграция с ИР](obshchie-mekhanizmy.md#integraciya-s-ir), [Панель «Приложения»](prilozheniya.md).
