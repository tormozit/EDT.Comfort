# Синхронизация базы

Диалоги синхронизации конфигурации с информационной базой при работе с ИР (динамическое обновление и др.).

## Уведомления Комфорт

При диалоге EDT **«Выбор действия»** (блокировка инфобазы для обновления):

- Если к базе **подключено приложение ИР** и в [панели «Приложения»](prilozheniya.md) включена колонка **«Динамическое обновление»** — Комфорт автоматически выбирает **«Обновить динамически»** в диалоге блокировки.
- После **динамического обновления** — уведомление с предложением **переподключить приложение ИР** для обновления метаданных в сеансе ИР.
- При **исключительной блокировке** без возможности динамического обновления — предложение **отключить приложение ИР**, если оно блокирует обновление базы.

## Мастер «Обновление конфигурации в приложениях»

- Колонка **«Изменений»** — число объектов проекта, ожидающих синхронизации с базой строки. Заполняется **только для приложений, помеченных «Обновить»**. Клик по числу открывает набор [«<Измененные ИмяБазы>»](nabory-obektov.md) — те же объекты списком.
- Флажок **«Исправлять проблемы после выгрузки в формат 8.5»** — убирает известный баг конвертации форм (лишний `ButtonImportance=Main` у кнопок).

См. [Интеграция с ИР](obshchie-mekhanizmy.md#integraciya-s-ir), [Панель «Приложения»](prilozheniya.md).
