# Навигатор
Дерево конфигурации и расширений.
## Возможности Комфорт
- [Фильтры по подстроке](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) в поле поиска — здесь доступен и иерархический вариант (точка делит фильтр на секции «тип.имя»).
- **Фильтр по набору** — кнопка на панели навигатора (переключатель): показать только объекты **активного** набора; вытесняет штатный фильтр по подсистемам.
- **Показать в проводнике** — контекстное меню: проводник Windows на файле/папке элемента.
- **Комфорт → Свернуть все другие** — свернуть все ветки дерева, кроме родителей текущего выделения ([общие механизмы](obshchie-mekhanizmy.md#svernut-vse-drugie)).
- **Комфорт → Добавить в набор объектов** — добавить выделенные объекты в активный набор.
- **Показать в структуре проекта** — контекстное меню: показать выделенный элемент в представлении **Структура проекта** ([#173](https://github.com/tormozit/EDT.Comfort/issues/173)).
- **Комфорт → Скопировать проект…** — копирует все файлы выбранного проекта в новый проект (новое имя и расположение), копия отвязывается от git (папка `.git` не копируется) ([#208](https://github.com/tormozit/EDT.Comfort/issues/208)).
- В представлении макета (обычного и общего) — краткий суффикс типа макета в скобках, например «ПечатьЧека (Табл)» ([#213](https://github.com/tormozit/EDT.Comfort/issues/213)).
- В представлении формы (обычной и общей) — суффикс типа основного реквизита (первый фрагмент до точки), например «ФормаЭлемента (СправочникОбъект)», «ФормаСписка (ДинамическийСписок)». Тот же суффикс — в диалоге выбора общей формы (свойства вроде основной формы истории данных).
- **Группировка общих модулей** по основе имени — визуально сворачивает семейства вроде `ВариантыОтветов` / `ВариантыОтветовКлиент` / `ВариантыОтветовКлиентСервер` / `ВариантыОтветовСлужебныйКлиент` в одну группу; структура конфигурации не меняется. Хвост имени — комбинация суффиксов набора 1 и не более одного суффикса набора 2 в любой позиции. Настройка: **Параметры → Комфорт → Группировать общие модули в навигаторе по имени** и два списка суффиксов ([#68](https://github.com/tormozit/EDT.Comfort/issues/68)).

## Копирование имён (Ctrl+C) :id=kopirovanie-imyon
При выделении одного или нескольких объектов **Ctrl+C** дополнительно кладёт в буфер **имена** объектов (по одному на строку) — удобно для вставки в сторонние приложения. Штатный формат LocalTransfer (объекты MdObject) сохраняется ([#235](https://github.com/tormozit/EDT.Comfort/issues/235)).
То же поведение — в дереве [«Структура проекта»](struktura-proekta.md).
## Двойной щелчок
- **Реквизит** (обычный, стандартный, общий, реквизит табличной части) — как в EDT: открывается редактор объекта МД с выделенным реквизитом; дополнительно активируется панель **Свойства** (она получает фокус последней) ([#140](https://github.com/tormozit/EDT.Comfort/issues/140), [#46](https://github.com/tormozit/EDT.Comfort/issues/46)).
