# Установка и обновление

## Через интернет (рекомендуется)

1. Главное меню → **Справка** → **Установить новое ПО…** → **Добавить**.
2. Указать URL сайта обновления (последняя версия, composite):

   `https://tormozit.github.io/EDT.Comfort/`

3. Отметить **EDT Comfort** → **Далее** → **Готово**.
4. Если всё сделано правильно, EDT предложит **перезапуск** — согласитесь.

Плагин **не требует** Eclipse JDT при установке. Для [орфографии](orfografiya.md) нужен модуль JDT UI — если его нет в EDT, установите через **Параметры → Комфорт → «Установить модуль орфографии (JDT)»** (или вручную с сайта Eclipse Releases).

Корневой composite-URL `https://tormozit.github.io/EDT.Comfort/` содержит **все архивные линейки** — в «Детали установки» отдельные строки с номером версии (1.0.0.19, 1.0.0.16, 1.0.0.15, …). Фиксированная линейка — по URL вида `https://tormozit.github.io/EDT.Comfort/1.0.0.14/`. Полный перечень — на [главной странице сайта](https://tormozit.github.io/EDT.Comfort/).

По умолчанию в диалоге установки включена галочка **«Show only the latest versions of available software»** — она скрывает архивные линейки, оставляя только последнюю. Снимите её, чтобы увидеть все версии сайта сразу.

## Без интернета (архив)

1. Скачать ZIP-файл с [релизов GitHub](https://github.com/tormozit/EDT.Comfort/releases) или с URL фиксированной версии, например:

   `https://tormozit.github.io/EDT.Comfort/1.0.0.13/`

2. Главное меню → **Справка** → **Установить новое ПО…** → **Добавить** → **Архив…** → выбрать скачанный ZIP-файл → **Добавить**.
3. Отметить **EDT Comfort** → **Далее** → **Готово** → перезапуск EDT.

## Обновление

Используйте тот же URL или архив новой версии.

В окне **«Доступное программное обеспечение»** при выборе расположения в списке **«Работать с»** Комфорт автоматически обновляет выбранный сайт, включая сайт из ZIP-архива, и заново загружает список доступного ПО. Это позволяет увидеть новую версию после замены архива по прежнему пути. Пункты выбора всех сайтов и только локальных сайтов автоматическое обновление не запускают.

Перед поиском версий для окна **«Доступные обновления»** Комфорт также обновляет сайты, участвующие в поиске. Повторный расчёт плана после выбора версий не загружает сайты заново.

Если установщик **не видит новую версию**:

1. В диалоге установки нажать **Управление…**
2. В списке сайтов нажать **Обновить** у сайта `https://tormozit.github.io/EDT.Comfort/`
3. Либо удалить сайт и **добавить заново** (при установке из архива — с именем установочного файла)

Плагин может показывать уведомление о доступной версии — см. [Настройки](nastroyki.md).

## Установка предыдущей версии

Комфорт поддерживает замену установленной версии более старой через **«Установить новое ПО…»**, включая переход на предыдущую сборку той же версии.

1. Открыть **Справка → Установить новое ПО…** и выбрать сайт Комфорта.
2. Снять флажок **«Показать только последние версии доступного ПО»**.
3. Отметить нужную версию **EDT Comfort** → **Далее**.
4. Проверить выбранную версию в плане изменений → завершить установку и перезапустить EDT.

Замена выполняется одной операцией. Зависимости выбранной версии должны быть совместимы с установленным ПО.

Для первого перехода вниз требуется сначала установить сборку Комфорта с поддержкой такой замены и перезапустить EDT. Если затем установлена архивная версия без этой поддержки, после перезапуска действуют возможности той архивной версии.
