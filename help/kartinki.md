# Картинки

Доработки диалогов и поля картинки ([#524](https://github.com/tormozit/EDT.Comfort/issues/524)).

## Выбор картинки

В окне **«Выбрать картинку»**, на вкладке **«Из конфигурации»**:

- **Добавить** — штатный мастер «Новая общая картинка» (как в EDT)
- **Изменить** — закрывает диалог выбора и открывает штатный редактор общей картинки
- **Показать в навигаторе** — раскрывает объект в панели «Навигатор»
- **Выбрать ИР** — выбор через Инструменты разработчика; после выбора строка активируется в списке конфигурации

Кнопки под списком — в одну строку. Окно нельзя сузить меньше ширины, достаточной для списка и превью.

Фильтр списка — при включённом **Улучшать списки** (см. [Улучшать списки](uluchshenie-spiskov.md)).

## Поле картинки

Во всех окнах с полем картинки (выбор, редактор общей картинки):

- **Ctrl+колёсико** — масштаб
- Контекстное меню: **Увеличить**, **Уменьшить**, **Оригинальный размер**
- Внизу поля — формат сжатия, размеры и цветовая глубина
