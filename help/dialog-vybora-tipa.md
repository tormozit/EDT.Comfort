# Диалог выбора типа

Диалог выбора типа данных (в т. ч. поле «Тип» в мастере «Новый реквизит»).

В поле **Тип** у реквизитов объектов метаданных и форм названия типов составного типа показываются в том же порядке, что и в окне **Редактирование типа данных**. Такой же порядок применяется к типам полей компоновки данных. Сортировка касается представления и не меняет порядок хранения типов в конфигурации; описание из одного типа не сортируется ([#768](https://github.com/tormozit/EDT.Comfort/issues/768)).

## Фильтры

- [Фильтры по подстроке](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) в списке типов — здесь доступен и иерархический вариант (точка делит фильтр на секции «категория.имя», например `Справ.Вал` найдёт `СправочникСсылка.Валюты`) ([#146](https://github.com/tormozit/EDT.Comfort/issues/146), [#147](https://github.com/tormozit/EDT.Comfort/issues/147)).

## Окно «Редактирование типа данных»

В окне редактирования типа данных доступны дополнительные возможности ([#148](https://github.com/tormozit/EDT.Comfort/issues/148)):

- **Флажок «Только помеченные»** — показать только отмеченные типы; состояние запоминается и применяется при открытии окна.
- **Кнопка «Лучший тип»** — помечает тип, подобранный по имени реквизита, как при автоподборе типа в окне «Новый реквизит». Если есть объект метаданных с именем, равным имени реквизита (определяемый тип, справочник, документ и т. п.), помечается его тип; при одинаковых именах определяемый тип важнее ссылочного. Иначе тип подбирается по словам имени, как в «Инструментах разработчика»: `ДатаНачала` — Дата, `СуммаДокумента` — Число, `ЭтоГруппа` — Булево, `ТзТовары` — ТаблицаЗначений, `Контрагент` — ссылка на похожий по имени справочник или определяемый тип, `КонтрагентИНН` — тип реквизита ИНН этого справочника. Если по словам имени тип не подобран, а 1С:Напарник в сети, тип подбирает он. Без флажка «Составной тип данных» пометка заменяет прежнюю, с флажком — добавляется к помеченным.
