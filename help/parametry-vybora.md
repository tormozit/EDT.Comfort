# Параметры выбора

Диалог **Редактирование параметров выбора** (составные типы, поля отбора).

## Автовыбор типа значения

При выборе **имени параметра** (колонка «Имя», значения вида `Отбор.*` / `Filter.*`) Комфорт **автоматически выставляет тип значения** в колонке «Значение» по метаданным поля отбора.

![Автоподстановка типа при выборе имени параметра](images/issue-49-1.png)

## Подбор имени связи параметров выбора

При добавлении связи параметров выбора Комфорт сначала проверяет одноимённый элемент отбора. Если его описание типа не совпадает с типом исходного реквизита или такого элемента нет, проверяются остальные элементы в порядке доступных имён. Выбирается первый элемент с совпадающим описанием типа; сравниваются состав типов и их квалификаторы. Если подходящего элемента нет, сохраняется штатный выбор EDT. Уже добавленные связи не меняются.
