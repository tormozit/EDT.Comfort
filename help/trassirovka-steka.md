# Трассировка стека

Штатная панель EDT **Трассировки стека** — многостраничная, по вкладке на каждую трассировку.

## Возможности Комфорт

- Двойной клик по строке узла **причины** ошибки запускает штатное действие «Добавить точку
  останова по исключению» и сразу подставляет причину в открывшийся диалог
  [«Остановка по ошибке»](tochki-ostanova.md) — без буфера обмена, причина уже разобрана EDT. Для
  строк кадров стека двойной клик не переопределён — работает штатный переход к исходнику в модуле.
- **Ctrl+C** / «Копировать» копирует текст только текущей выделенной строки дерева, а не всю
  трассировку целиком, как штатная команда этой панели.
