# Наборы объектов

Представление **Наборы объектов** (категория Комфорт). Списки объектов метаданных, привязанные к **проекту** EDT.

## Назначение

- Хранить рабочие подмножества объектов конфигурации (задачи, рефакторинг, обзор).
- Фильтровать **навигатор** по активному набору.
- Быстро возвращаться к объектам из набора.

## Динамические наборы

Состав такого набора не хранится, а вычисляется при каждом показе. Редактировать его вручную нельзя, колонка **Объектов** обновляется автоматически.

### «<Измененные>» — по изменениям Git

Для каждого проекта под Git создаётся автоматически: в него попадают объекты метаданных, затронутые незакоммиченными изменениями (по индексу Git). Удалить набор нельзя ([#249](https://github.com/tormozit/EDT.Comfort/issues/249)).

### «<Измененные ИмяБазы>» — по изменениям для информационной базы

Содержит объекты проекта, ожидающие синхронизации с конкретной информационной базой — те же, что EDT отправит в базу при обновлении конфигурации. Детализация — до форм, макетов и команд: изменение формы даёт строку `Справочник.Валюты.Форма.ФормаСписка`, а не строку самого справочника (в отличие от набора по изменениям Git, который сворачивает изменения до владеющего объекта).

Набор создаётся командой **Комфорт → Показать изменения** в панели [«Приложения»](prilozheniya.md), после чего его строка становится активной. В отличие от git-набора, этот набор можно удалить — команда создаст его заново. При удалении приложения набор по его базе удаляется автоматически.

**Когда обновляется состав.** Вычисление состава запускает служебный поток синхронизации EDT и занимает около половины секунды, поэтому оно выполняется только пока набор **выбран** в таблице наборов: в этом режиме правки в проекте сразу меняют список. Для невыбранного набора в колонке **Объектов** показывается `?` — число не показывается вовсе, потому что без пересчёта оно было бы недостоверным.

В таблице наборов видны только наборы **открытых** проектов. При закрытии проекта его наборы скрываются, при повторном открытии — снова появляются.

## Основные действия

- Создание и переименование наборов, переключение **активного** набора двойным щелчком (отметка «●»).
- Таблица объектов: имя, путь; фильтр по подстроке.
- **Ctrl+T** — показать объект текущей строки в [навигаторе](navigator.md).
- Контекстное меню: копировать ссылку, удалить из набора.
- Добавление объектов из [навигатора](navigator.md) и [последних мест](poslednie-mesta.md).
- Из **списка файлов проекта** (представление ресурсов) — контекстное меню **Комфорт → Добавить в набор …** ([#163](https://github.com/tormozit/EDT.Comfort/issues/163)).

## Фильтр навигатора

При включённом **Фильтре по набору** в навигаторе отображаются только объекты активного набора. См. [Навигатор](navigator.md).

## Открытие панели

Назначьте команду **Наборы объектов** в **Параметры → Клавиши** (категория Комфорт) или откройте через **Показать представление → Прочее → Наборы объектов**.
