# Отбор по подсистемам

Диалог **Отбор по подсистемам** (в коде EDT — «Фильтр по подсистемам») в навигаторе; тот же диалог используется в **[сравнении конфигураций](sravnenie-konfiguracij.md)** для отбора по стороне сравнения.

## Возможности Комфорт

- Автораскрытие ветки проекта по текущему выделению в навигаторе.
- Запоминание размеров и положения окна между сеансами.
- Штатное поле фильтра заменено на [фильтр по подстроке](obshchie-mekhanizmy.md#filtry-po-podstroke-v-spiskah) Комфорт с раскраской вхождений и историей запросов (**Ctrl+↓**) ([#82](https://github.com/tormozit/EDT.Comfort/issues/82)).
- **Ctrl+клик** по серой (унаследованной) пометке превращает соседние динамические пометки в статические, не сбрасывая пометки всего поддерева, как это делает штатное поведение — подсказка об этом выводится под деревом.
- **Ctrl+C** на дереве копирует текст активной ячейки.
- Флажок **«Скрывать объекты выбранных подсистем (чёрный список)»** — выбранные подсистемы **скрывают** объекты вместо штатного белого списка ([#241](https://github.com/tormozit/EDT.Comfort/issues/241)).
- В подменю **Комфорт** добавлены **Установить пометку с потомками** / **Снять пометку с потомками** для выделенной подсистемы; недоступно при включённом **«Включать объекты из подчинённых подсистем»**.
- В подменю **Комфорт** добавлены **«Сохранить состояние фильтра…»** и **«Загрузить состояние фильтра…»**: пометки подсистем, флаги «Включать объекты из…», режим чёрного списка ([#243](https://github.com/tormozit/EDT.Comfort/issues/243)).
