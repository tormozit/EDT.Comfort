# Последние места

Представление **Последние места** (категория Комфорт). Открывается по **Ctrl+3** или кнопке **Последние** на панели.

## Возможности

- Таблица недавно посещённых **методов** и **объектов метаданных** с фильтром по подстроке.
- Двойной щелчок или Enter — переход к месту. Не запускает подключение ИР; уже подключённое приложение используется для нормализации ссылок на формы и макеты.
- **Ctrl+T** — [показать объект в навигаторе](navigator.md).
- Перетаскивание строки на [навигатор](navigator.md) — то же, что **Ctrl+T**: выделяется соответствующая строка в дереве.
- Перетаскивание строки на список панели [«Индексирование Git»](git-izmeneniya.md) — выделяет файлы объекта без вложенных.
- **Добавить в набор объектов** — перенести выделенные записи в активный набор.
- Контекстное меню: копирование, удаление записей, переход.
